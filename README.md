## 🚀 Installation

### Termux (Android)

```bash
pkg update && pkg upgrade -y
pkg install git python -y
git clone https://github.com/naveen-anon/UPI-_OSINT.git
cd UPI-_OSINT
pip install colorama requests
python upi_osint_pro.py
```

## Kali Linux / Ubuntu / Windows ##
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install git python3 python3-pip -y
git clone https://github.com/naveen-anon/UPI-_OSINT.git
cd UPI-_OSINT
pip3 install colorama requests
python3 upi_osint_pro.py
```
## 📖 Usage
Run the tool:
```
python upi_osint_pro.py
```
***Options:***
> 10-digit Phone Number → UPI mapping aur registration check
> UPI ID (e.g. user@paytm) → Deep analysis
> Claimed Name + Preview Name (optional) for better accuracy
> Type exit to quit.
